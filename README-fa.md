# کپچای دسترس‌پذیر — پروژه اندروید

این پروژه یک نمونه اولیه اندرویدی است که به کاربر اجازه می‌دهد تصویر را با انتخاب‌گر استاندارد اندروید انتخاب کند و به یک سرور HTTPS ارسال کند. رابط کاربری از کنترل‌های استاندارد اندروید استفاده می‌کند تا با TalkBack سازگار باشد.

## ساخت APK به‌صورت آنلاین

فایل‌های این پروژه را در مخزن خصوصی GitHub خود، با حفظ ساختار پوشه‌ها، بارگذاری کنید. فایل workflow در مسیر زیر قرار دارد:

`.github/workflows/build-apk.yml`

پس از ثبت فایل‌ها در شاخه `main`، از زبانه **Actions** اجرای workflow را باز کنید. در پایان، در بخش **Artifacts** فایل `captcha-accessible-debug-apk` را دانلود کنید و فایل ZIP آن را باز کنید تا `app-debug.apk` را بردارید.

## تنظیم آدرس سرور

در برنامه، آدرس کامل endpoint را وارد کنید؛ برای نمونه:

`https://example.com/api/v1/upload-image`

سرور باید endpoint از نوع `POST multipart/form-data` با نام فیلد فایل `file` را بپذیرد، مطابق سرور FastAPI فعلی.

## نکات مهم اتصال

- آدرس محلی مثل `10.x.x.x` فقط در شبکه محلی مربوطه قابل دسترسی است و برای کاربران اینترنتی مناسب نیست.
- برنامه عمداً گواهی TLS نامعتبر یا خودامضا را نادیده نمی‌گیرد. سرور باید گواهی HTTPS معتبر داشته باشد.
- این نسخه تصویر را فقط پس از انتخاب صریح کاربر ارسال می‌کند. به‌طور خودکار از صفحات دیگر اسکرین‌شات نمی‌گیرد و کپچا را دور نمی‌زند.
- این خروجی نسخه آزمایشی debug است، نه نسخه آماده انتشار در فروشگاه. برای انتشار عمومی باید امضای release، حریم خصوصی، امنیت سرور و تست دستگاه‌ها انجام شود.
